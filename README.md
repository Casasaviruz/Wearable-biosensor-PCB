# Wearable-biosensor-PCB

A battery powered double sided PCB sensor meant to monitor the heart rate, breathing, temperature and sleep and active cycles of lab mice, made as small and non invasive as possible, data is transmitted through Bluetooth

Final Project — CSE 332 (Analog and Digital Circuits), DePaul University,
winter 2026.

# Specifications

- Dimensions: 27mm x 18mm
- Weight: ~ 3.05g (with battery)
- Microcontroller: nRF52832 (ARM Cortex-M4 + radio BLE)
- Sensors: MAX30101 (heart rate/ breathing), TMP117
  (temperature), LSM6DSL (accelerometer/gyroscope)
